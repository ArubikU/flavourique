# Screenshots para PWA

Este directorio debe contener las siguientes capturas de pantalla:

## screenshot-wide.png (1280x720)
Captura de la pantalla principal en desktop mostrando:
- Header con navegación
- Hero section
- Grid de recetas
- Footer

## screenshot-mobile.png (390x844)
Captura de la pantalla principal en móvil mostrando:
- Header responsive
- Hero section
- Lista de recetas en columna
- Navegación inferior (si aplica)

---

Para generar las capturas:
1. Abre la app en Chrome
2. Usa DevTools > Responsive mode
3. Configura el tamaño correcto
4. Captura con Cmd/Ctrl + Shift + P > "Capture screenshot"
